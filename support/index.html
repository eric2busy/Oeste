The libraries

Oeste is three libraries. They share one issue tracker, so bug reports and requests live in one place.

Get help

Oeste has no support desk. If you are stuck, work through these steps in order.

  1. Read the library spec first. Start with the docs for your library, including its llms.txt. Most questions are answered there.
    • Topanga docs · Topanga llms.txt
    • Huntington docs · Huntington llms.txt
    • Mesa docs · Mesa llms.txt
  2. Search existing GitHub issues. Someone may have hit the same thing. Search the issues before you open a new one. Search issues
  3. File a new issue. If the spec and the issues do not answer it, open a new issue. Say what you tried and what you saw. Open a new issue

What Oeste does not offer

No response-time promise. No email support. No contact form.

And never post personal info: no passwords, keys, or private details in an issue.

Report a bug

Found something broken? Open an issue on GitHub. Include everything below so it can be reproduced.

  • Library and version (for example, Huntington 0.2.0).
  • Figma version or browser (whatever you were using when it broke).
  • Steps to reproduce, in order.
  • Expected behavior and actual behavior.
  • Screenshots, if they help.

Beta note

All three libraries are Beta. APIs and component behavior can still change between minors. Pin the version you ship with, and read the changelog before you upgrade.

FAQ

What license are the libraries under?

MIT. You can use all three libraries in personal and commercial projects, free. Keep the MIT license notice in the code you ship.

Can I use Oeste libraries in commercial or client work?

Yes. MIT covers commercial use, including work you bill a client for. There is no fee, no royalty, and no separate commercial license.

Is there a paid tier?

No. There is no paid tier, no premium set of components, and no paywall. Everything is MIT licensed and free.

Can I request a component?

Yes. Open an issue on GitHub and describe what you need and why. Requests are considered, not promised, and the answer may be no.

Are there known contrast findings?

Yes, and they are documented. Topanga marks Canyon Rust decorative only because it does not meet 4.5:1 for small text. Mesa lists four exceptions in its Accessibility guide and says never to use those pairs as normal-size body text. Check the Accessibility guide in the library you use for the current list.

Can I mix libraries in one project?

You can, but keep their tokens separate. Each library has its own tokens and its own look, so a mixed page will look mixed. Pick one library per surface when you can.
